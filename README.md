# MOKOMOKO Website

Static HTML/CSS/JavaScript baseline reconstructed from the current Canva Website PDF export.

## Local preview

Serve this directory with any static file server and open `index.html`.

## Deployment

GitHub Pages deploys the repository root through `.github/workflows/pages.yml`.

## Content notes

- `CANVA_SITE_AUDIT.md` records the source layout and copy.
- `IMAGE_REPLACEMENT.md` lists original image files still required.
- The existing booking form is linked as a separate page and is not embedded or copied into this project.
